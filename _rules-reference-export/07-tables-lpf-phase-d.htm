Game End

TriggerOutcome
The Bank runs out of moneyThe game ends the next time a Stock Round would start
…during an Operating RoundFinish the current set of Operating Rounds, then the game ends
…during a Stock RoundFinish the Stock Round and one set of Operating Rounds, then the game ends
A player goes bankruptThe game ends immediately

The winner is the wealthiest player: personal cash, plus the value of their shares, plus the face value of any private companies they still own.
